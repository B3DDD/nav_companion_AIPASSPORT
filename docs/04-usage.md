# 使用说明

## 一、准备

| 需要 | 说明 |
|---|---|
| 手机 | 安卓 12（`minSdk 31`）及以上。已验证华为 Mate 60 Pro / HarmonyOS 4.2 |
| 卡片 | AI Passport（ESP32-C3 / 8 MB Flash） |
| 数据线 | 能传数据的 USB 线（刷机用） |
| GPX 文件 | 在两步路、高驰等 App 里导出你要跑的路线 |

### 关于 GPX 的 CP

卡片的进度条刻度来自 GPX 里的**命名航点**：

- 两步路：导出时勾选「途经点 / 航点」
- 高驰（COROS）：导出的 `<wpt>` 会自动带上，如「起终点」「cp1/7.5」
- ovitalmap 等：`<wpt>` 带 `<name>` 即可

**起终点会被自动排除**，不计入 CP：

- 名字含「起终点 / 起点 / 终点 / 出发 / 完赛 / start / finish」；
- 或者位置落在距起点或终点 100 米以内（覆盖"名字没写起点"的情况）。

导入后 App 第二行会显示「轨迹 N 点 | CP N 个 | 爬升 X m」，**N 就是识别到的 CP 数量**。若 N = 0，说明文件没有命名航点，此时进度条只有填充、没有刻度，大数字退化为「距终点」。

## 二、刷入固件（只需一次）

1. 电脑用 Chrome / Edge 打开玩法页，点「安装」，按提示从 `0x0` 刷入；
   或打开 <https://ai-passport.folotoy.cn/tools/web-flasher/>，选下载好的 `.bin`，从 `0x0` 刷入，波特率保持 115200。
2. 刷完卡片自动重启，屏幕出现「等待手机连接」，说明固件就位。

> 自己编译的固件用 `idf.py merge-bin` 生成合并镜像后刷 `0x0`，不要只刷 `0x10000` 的 app 分区。

## 三、安装手机 App

1. 从玩法页说明里的网盘链接下载 APK（文件名形如 `导航副屏-app（11.22）.apk`）；
2. 传到手机安装，提示「未知来源」时允许本次安装；
3. 打开 App，把**定位、附近设备（蓝牙）、通知**三项权限都允许。

## 四、先设后台，避免锁屏被系统关掉

越野时锁屏是常态，Android 会主动限制后台定位和 BLE。

- **华为 / HarmonyOS**：设置 → 应用和服务 → 应用启动管理 → 导航副屏 → 关闭「自动管理」→ 勾选**自启动、关联启动、后台活动**。
- **小米**：设置 → 应用设置 → 应用管理 → 导航副屏 → 省电策略 → 无限制；同时允许「自启动」。
- **OPPO / vivo / 三星**：在「电池优化」或「后台耗电管理」里把该应用设为**不限制**。

找不到入口时，就把所有带「后台限制 / 省电 / 电池优化」的选项设为最宽松。

## 五、开始导航

1. 卡片长按电源键开机，屏幕点亮。
2. App 点「选择 GPX 轨迹」，选刚导出的文件。第三行会显示轨迹信息。
3. **确认方向**：默认「正穿」。如果要反着跑这条线路，点一下「方向」按钮切成「反穿」——剩余里程和 CP 顺序都会跟着调转。
4. 点「开始导航」。App 自动搜索并连接卡片，最下面一行变成「已连接, 推送中」。

## 六、走到起点才出发

卡片顶部显示「距起点 XXX」和「走到起点 100m 内」。

走进起点 100 米范围并**连续确认两次**后，状态变成绿色「已出发」，累计距离和累计爬升才开始记录。这样热身、拍照、排队时乱走的里程不会混进成绩。

> 在自己家附近测试：可以选一条起点就在身边的路线，或先走到路线起点附近再开始。

## 七、跑步中

### 导航页（默认）

| 位置 | 内容 |
|---|---|
| 顶部状态 | 待出发 / 已出发 / 已到达终点；丢信号时显示橙色「无定位」 |
| 大数字 | 到下一个 CP 的**沿路里程**；跑过最后一个 CP 后变成「距终点」；名称显示在其上方 |
| 偏离 | 绿（30 m 内）/ 黄 / 红（100 m 以上），超过 100 m 会响提示音 |
| 剩余 | 全程剩余里程 |
| 海拔 | 当前海拔 |
| 底部进度条 | 填充比例 = 完成进度；琥珀色小刻度 = 各 CP 位置 |

### 数据页（按上 / 下键切换）

累计距离 → 累计爬升 → CP 个数 → 剩余 → 海拔 → 路线总长。

其中 **「累计 + 剩余 ≈ 路线总长」** 可以当场核对数据有没有算偏。

### 按键

| 键 | 短按 |
|---|---|
| 上 / 下 | 导航页 ⇄ 数据页 |
| OK | 切换亮度（暗 ↔ 亮） |

## 八、结束

回到 App 点「停止」即可。停止后卡片回到「等待手机连接」。

## 常见现象

| 现象 | 说明 |
|---|---|
| 卡片显示「等待手机连接」 | 手机没连上：确认 App 已点「开始导航」、手机蓝牙开着、卡片在附近（10 m 内） |
| 卡片顶部「无定位」橙色 | 手机端没拿到 GPS（室内、隧道、冷启动）；卡片保留最后读数 |
| 进度条没有刻度 | GPX 里没有命名航点，见上文「关于 GPX 的 CP」 |
| 卡在「距起点」不变身「已出发」 | 还没进起点 100 m，或定位精度差；App 第三行会显示距起点的实时距离 |
| 数字明显偏大/偏小 | 先看「累计 + 剩余」是否等于路线总长；不等说明轨迹或定位异常 |
| 手机锁屏后数据停更 | 后台被系统限制，按第四节重设 |
